# Джарвис для Ray-Ban Meta

Личный голосовой ассистент на Claude для очков Ray-Ban Meta (Gen 2) и iPhone — замена Meta AI там, где он не работает (в том числе в Узбекистане и других странах СНГ). Видит камерой очков, слышит их микрофонами, отвечает живым голосом через их динамики, помнит вас и делает дела на телефоне.

```
Очки Ray-Ban Meta ── Bluetooth ──► iPhone: это приложение
  камера 12 МП (DAT SDK)            ├─ ElevenLabs Scribe Live: речь → текст потоком (или Apple Speech без ключа)
  5 микрофонов (HFP)                ├─ Claude API: разговор, снимки, инструменты, веб-поиск, память
  динамики (HFP / A2DP)             └─ ElevenLabs v4 Turbo: ответ → речь потоком (или голос iOS)
```

## Что умеет

- **Свой характер.** При первом запуске вы придумываете ассистента: имя («Джарвис», «Пятница» или любое своё), характер (тёплый, спокойный, с иронией, деловой или описанный своими словами), обращение на «ты» или «вы», длину ответов и чувство юмора.
- **Разговор как с человеком.** Речь распознаётся потоком, ответ начинает звучать, пока Claude ещё пишет его. Ассистент сам понимает, что фраза обращена к нему, и молчит, когда вы говорите с другими; имя называть не обязательно. Сразу после ответа можно уточнять без обращения.
- **На связи — с телефоном в кармане.** Разговор оформляется как звонок: микрофон работает с заблокированным экраном, очки ведут себя как при телефонном разговоре. Ассистент может и сам позвонить вам в очки — по команде Siri или автоматизации «надел очки».
- **Три языка управления.** Русский, узбекский (латиница) и английский, в том числе вперемешку в одной фразе: заговорите на любом — ответит на нём, одним голосом.
- **Зрение.** «Что передо мной?», «прочитай вывеску», «переведи меню» — снимок камерой очков.
- **Память как в Obsidian.** Ассистент сам записывает важное о вас, близких, планах в заметки Markdown и помнит это между разговорами. Заметки можно читать, править и перенести в Obsidian.
- **Дела.** Календарь (что у меня завтра, добавь встречу), Напоминания, таймеры и будильники.
- **Связь.** SMS/iMessage, WhatsApp, Telegram, письма и звонки по имени из контактов. iOS не даёт отправлять без нажатия, поэтому ассистент открывает готовое сообщение, а вы нажимаете «Отправить».
- **Почта.** «Есть новые письма?», «что пишет банк?» — чтение Gmail, Яндекс, Mail.ru, iCloud по IMAP с паролем приложения.
- **Переводчик в реальном времени.** Свободный разговор: переводчик сам определяет, кто говорит, показывает перевод, пока человек ещё не договорил, вам переводит в очки, собеседнику — из динамика телефона. 17 языков, включая узбекский, казахский, турецкий, китайский.
- **Siri и кнопка «Действие».** «Спросить Джарвис» открывает приложение и сразу слушает; «Джарвис, на связь» — ассистент звонит в очки, даже если телефон заблокирован; «Переводчик в Джарвис» открывает переводчик.
- **И ещё.** Маршруты (Яндекс Карты, Google Maps, Карты Apple), «Где я?», поиск в интернете (погода, новости, курсы), запуск ваших команд из приложения «Команды» — так подключаются умный дом и любые сервисы.

Чего не умеет из-за ограничений iOS: читать переписку в Telegram, WhatsApp, SMS и чужие уведомления — это не разрешено ни одному приложению из App Store или Sideloadly. Ассистент так и отвечает и предлагает то, что возможно.

## Бесплатно: GitHub Actions + Sideloadly

Облачный Mac в GitHub Actions собирает приложение без подписи. Потом [Sideloadly](https://sideloadly.io) на вашем Mac подписывает его вашим обычным Apple ID и ставит на iPhone по кабелю. Платить Apple не нужно.

1. **Код на GitHub.** Загрузите эту папку в репозиторий. В **публичном** репозитории минуты GitHub Actions бесплатны без ограничений. В приватном бесплатно примерно 200 минут macOS в месяц, это около 15 сборок. Секретов в коде нет: API-ключ Claude вводится в самом приложении.
2. **Сборка.** После каждого push запускается workflow **CI**. Через 10–15 минут откройте: Actions → последний запуск → внизу **Artifacts → RayBanClaude-ipa**. Скачается zip; внутри `RayBanClaude.ipa`.
3. **Sideloadly.** Скачайте и установите с [sideloadly.io](https://sideloadly.io) (есть версия для macOS). Подключите iPhone кабелем и на телефоне нажмите «Доверять этому компьютеру».
4. **Установка.** Перетащите `RayBanClaude.ipa` в окно Sideloadly, введите Apple ID и нажмите **Start**. Пароль Apple ID попадает в стороннюю программу, поэтому лучше завести для этого отдельный бесплатный Apple ID. Если Sideloadly сообщит, что идентификатор приложения занят: Advanced options → Bundle ID → впишите свой, например `com.<ваше-имя>.raybanclaude`.
5. **Разрешить запуск на iPhone.**
   - Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить; телефон перезагрузится.
   - Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
6. **Очки.** В Meta AI включите режим разработчика: Настройки → ваши очки → Developer Mode. Если переключателя нет: Настройки → App Info, нажмите 5 раз на номер версии. После обновления прошивки очков режим может выключиться — включите снова.
7. **Первый запуск.** Приложение проведёт через [первую настройку](#первая-настройка): имя и характер ассистента, ключи, микрофон и очки. Потом нажмите микрофон и спросите «Что передо мной?».

Ограничения бесплатного Apple ID:
- **7 дней.** Через неделю приложение перестанет открываться. Повторите шаг 4 с тем же IPA: данные и API-ключ сохранятся. Sideloadly умеет обновлять подпись автоматически, если Mac включён и находится в той же сети Wi-Fi.
- **Не больше 3 приложений**, подписанных бесплатным Apple ID, одновременно на одном телефоне.
- **Без Wi-Fi-канала очков.** В неподписанной сборке нет разрешения Hotspot, поэтому SDK Meta передаёт видео с камеры по Bluetooth Classic. Так работает пример Meta BirdSpotter. Поток идёт в меньшем разрешении, но для снимков по запросу этого достаточно.
- Сборка в CI — Debug: в настройках приложения есть раздел «Отладка» с виртуальными очками (см. [«Без очков»](#без-очков)).

## Запуск из Xcode

1. Установите Xcode из App Store и выберите его:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
2. Откройте проект:
   ```bash
   open "RayBanClaude.xcodeproj"
   ```
   Xcode сам скачает Meta Wearables DAT SDK 1.0.1 (Swift Package).
3. В **Signing & Capabilities** выберите свою команду (Team) и замените Bundle Identifier `com.example.raybanclaude` на уникальный, например `com.<ваше-имя>.raybanclaude`. Надёжнее сделать это в `project.yml` (`DEVELOPMENT_TEAM`, `PRODUCT_BUNDLE_IDENTIFIER`) и выполнить `xcodegen generate`: тогда настройки не потеряются при пересоздании проекта. Если бесплатный аккаунт не даёт подписать приложение из-за Hotspot / Wi-Fi Info в `RayBanClaude.entitlements`, попробуйте убрать эти два ключа: по документации DAT видеопоток идёт по Bluetooth Classic, а Wi-Fi нужен для больших объёмов данных (без Wi-Fi-канала не проверялось).
4. Подключите iPhone, выберите его как устройство и нажмите **Run**.
5. В приложении: вставьте API-ключ → «Подключить очки» (откроется Meta AI, подтвердите) → «Разрешить камеру» → нажмите микрофон и спросите «Что передо мной?».

## TestFlight без Xcode

Собирает и подписывает облачный Mac в GitHub Actions; от вас нужны только браузер и iPhone.

**Обязательно:** платное членство [Apple Developer Program](https://developer.apple.com/programs/) (99 $ в год) — без него TestFlight недоступен. Оформить можно в приложении Apple Developer на iPhone.

1. **Код на GitHub.** Создайте приватный репозиторий и загрузите туда эту папку. Workflow **CI** (`.github/workflows/ci.yml`) сам запустится, прогонит тесты и соберёт приложение — так видно ошибки компиляции, аккаунт Apple для этого не нужен.
2. **Bundle ID.** [developer.apple.com → Identifiers](https://developer.apple.com/account/resources/identifiers/list) → «+» → App IDs → App. Explicit Bundle ID, например `com.<ваше-имя>.raybanclaude`. В Capabilities отметьте **Access Wi-Fi Information** и **Hotspot** (их требует Wi-Fi-канал Meta DAT).
3. **Приложение в App Store Connect.** [App Store Connect](https://appstoreconnect.apple.com) → Приложения → «+» → Новое приложение: iOS, уникальное название, язык, выбранный Bundle ID, любой SKU. Затем в «Информация о приложении» скопируйте **Apple ID** (10 цифр).
4. **API-ключ.** App Store Connect → Пользователи и доступ → Интеграции → App Store Connect API → «+». Доступ **App Manager**. Скачайте `.p8` (скачать можно только один раз) и запишите **Key ID** и **Issuer ID**.
5. **Ключ сертификата.** Один раз создайте RSA-ключ — по нему CI будет переиспользовать один и тот же сертификат дистрибуции:
   ```bash
   ssh-keygen -t rsa -b 2048 -m PEM -f ~/raybanclaude_cert_key -q -N ""
   ```
6. **Настройки в GitHub:** репозиторий → Settings → Secrets and variables → Actions.

   | Тип | Имя | Значение |
   |---|---|---|
   | Variable | `BUNDLE_ID` | Bundle ID из шага 2 |
   | Variable | `APP_STORE_APPLE_ID` | Apple ID приложения из шага 3 |
   | Variable | `APP_STORE_CONNECT_ISSUER_ID` | Issuer ID |
   | Variable | `APP_STORE_CONNECT_KEY_IDENTIFIER` | Key ID |
   | Variable | `APPLE_TEAM_ID` | Team ID (необязательно; developer.apple.com → Membership) |
   | Secret | `APP_STORE_CONNECT_PRIVATE_KEY` | всё содержимое `.p8`, вместе со строками `BEGIN/END` |
   | Secret | `CERTIFICATE_PRIVATE_KEY` | всё содержимое `~/raybanclaude_cert_key` |

7. **Сборка.** Actions → **TestFlight** → Run workflow. Минут через 15–20 сборка уйдёт в App Store Connect, ещё 10–30 минут Apple её обрабатывает.
8. **Установка.** App Store Connect → приложение → TestFlight → «Внутреннее тестирование» → создайте группу и добавьте себя. На iPhone поставьте приложение **TestFlight** и установите сборку оттуда.

Важно:
- **Только внутреннее тестирование.** Внутренним тестировщикам (до 100 человек из вашей команды App Store Connect) проверка Apple не нужна. Внешнее тестирование требует Beta App Review, а приложения с Meta DAT (протокол внешних аксессуаров) проверку Apple пока не проходят.
- **Лимиты GitHub.** В приватном репозитории бесплатно 2000 минут в месяц, но минуты macOS считаются ×10 — это примерно 200 минут, около 10 сборок. В публичном репозитории минуты бесплатны, но код увидят все (секретов в коде нет: API-ключ Claude вводится в самом приложении).
- **Номер сборки** берётся автоматически: последний номер в TestFlight + 1.

### Без очков

В Debug-сборке в настройках есть раздел **«Отладка → Подключить виртуальные очки»** (MockDeviceKit из DAT):
- на iPhone «камерой очков» становится задняя камера телефона, микрофон — телефонный;
- в симуляторе снимок — тестовая картинка `RayBanClaude/Resources/mock_photo.jpg` (вывеска кафе и кружка), а вопрос можно напечатать в поле «Спросить текстом…».

## Первая настройка

Семь коротких шагов, всё можно поменять потом в «Настройках»:
1. Имя ассистента — по нему он откликается в режиме «Без рук».
2. Характер.
3. Язык управления, обращение («ты» или «вы»), длина ответов, юмор.
4. О вас: имя и то, что ассистенту стоит знать. Это сразу попадает в память, в заметку «Обо мне».
5. Ключи: Claude (обязательно) и ElevenLabs (живой голос и узбекский).
6. Микрофон и подключение очков через Meta AI.
7. Готово — ассистент здоровается своим голосом.

## Память

Память — папка обычных файлов Markdown. Ассистент видит её как `/memories` и сам ведёт заметки:
- `Обо мне.md` — главное о вас; подставляется в начало каждого разговора;
- `Люди/<Имя>.md`, `Места/…`, `Дела/…` — связаны ссылками `[[Имя]]`, как в Obsidian.

Вкладка «Память»: поиск, чтение с переходами по ссылкам, правка, новые заметки. Папка видна в приложении «Файлы» (На iPhone → RayBanClaude → Память). Чтобы читать её в Obsidian: меню «…» → «Сохранить копию в Файлы» → выберите папку вашего хранилища Obsidian. Пароли, коды и номера карт ассистент не записывает.

## Почта

Настройки → Почта: адрес и **пароль приложения** (не обычный пароль):
- Gmail — Аккаунт Google → Безопасность → Пароли приложений (нужна двухэтапная проверка);
- Яндекс — Яндекс ID → Безопасность → Пароли приложений → Почта, и включить IMAP в «Почтовых программах»;
- Mail.ru — Настройки → Безопасность → Пароли для внешних приложений;
- iCloud — appleid.apple.com → Пароли приложений.

Сервер для этих почт определяется сам, для других его можно указать. Письма только читаются (EXAMINE и BODY.PEEK) и не помечаются прочитанными. Outlook и Hotmail для личных аккаунтов теперь требуют вход через OAuth — он пока не поддерживается.

## На связи: телефон в кармане

iOS не даёт приложению включить микрофон, когда оно уже свёрнуто. Исключение — звонки. Поэтому долгий разговор идёт как звонок (CallKit):

- **Вы звоните ассистенту:** кнопка «На связи» на главном экране. Дальше телефон можно заблокировать и убрать в карман.
- **Ассистент звонит вам:** Siri «Джарвис, на связь» или автоматизация в приложении «Команды» (Bluetooth → ваши очки → «Выйти на связь»). Очки звонят, вызов принимается касанием дужки. Это работает и с заблокированным телефоном.
- **Закончить:** скажите «Отбой» или завершите вызов.
- **После обычного телефонного звонка** ассистент возвращает звук сам, а если iOS не разрешает — перезванивает.

Цена: пока идёт такой звонок, звук в очках телефонного качества, музыка на паузе, очки расходуют заряд как при разговоре. Режим «Не беспокоить» может заглушить вызов — разрешите приложению звонки в настройках фокусирования.

В режимах «На связи» и «Без рук» ассистент отвечает не на всё подряд (Настройки → Разговор → «Когда отвечать»): сам понимает, что обращаются к нему, только по имени или на каждую фразу.

**Жесты очков (эксперимент).** Настройки → «На связи и фон» → «Жесты очков»: двойное касание дужки или кнопка камеры вызывают ассистента и перебивают ответ. Это пробный модуль Inputs из Meta DAT; что присылают именно ваши очки, видно в журнале.

**Журнал.** Настройки → «Журнал»: что происходило с микрофоном, распознаванием, голосом, звонком и очками, в том числе в фоне. Им можно поделиться одним касанием — так проще разобраться, если что-то пошло не так.

## Переводчик

- **Разговор:** оба говорят свободно. Распознавание идёт потоком и само определяет, на каком из двух языков сказана фраза. Черновой перевод появляется, пока человек ещё говорит, и уточняется в конце фразы. Перевод его слов звучит у вас в очках, перевод ваших — из динамика телефона. Нужен ключ ElevenLabs; без него переводчик слушает только собеседника.
- **По очереди:** нажмите «Я» и скажите фразу; потом нажимает собеседник. Надёжнее в шуме. Меню «…» → «Показать собеседнику» — перевод на весь экран.
- Переводит Claude Haiku 5.5 — быстро и дёшево: фраза стоит меньше сотой доли цента.

## Языки

| | С ключом ElevenLabs | Без ключа |
|---|---|---|
| Распознавание | Scribe v3 Live потоком: русский, узбекский, английский, смешанная речь | Apple Speech на устройстве: русский и английский |
| Голос | v4 Turbo потоком: все три языка одним голосом | голос iOS: русский и английский |

У Apple нет распознавания, голоса и перевода для узбекского, поэтому для него нужен ключ ElevenLabs. «Смешанная речь» (Настройки → Разговор) понимает узбекский и русский вперемешку в одной фразе. Голоса носителей узбекского в списке помечены «узб.».

## Скорость и расход API

- **Потоком на каждом шаге:** распознавание заканчивает фразу, как только сервер предсказал конец реплики; Claude не размышляет перед первой фразой («Отвечать сразу», для Sonnet 5.5 это `thinking: between_tools`); озвучка начинается с первых слов ответа. Пока работает медленный инструмент (камера, почта, поиск), ассистент коротко говорит «Смотрю» или «Ищу».
- **Модель по умолчанию — Claude Sonnet 5.5** ($2 / $10 за миллион токенов): лучший баланс скорости и качества узбекского. **Haiku 5.5** ($0,10 / $0,50) — самый быстрый и дешёвый, **Opus 5.5** — для сложных задач.
- **Кэширование промпта:** характер, инструменты и память лежат в начале запроса и кэшируются — повторное чтение стоит в 20 раз дешевле.
- **Распознавание не платит за тишину:** в режимах «Без рук» и «На связи» поток открывается, только когда кто-то заговорил. Scribe Live стоит около $0,22 за час речи.
- **Фильтр обращения** — отдельный короткий запрос к Haiku 5.5: чужие разговоры не попадают в основную модель и почти ничего не стоят.
- **Экономия на длинных разговорах** (включено): сервер убирает старые снимки и результаты поиска. Разговор сбрасывается после 10 минут тишины.

## Дизайн

Мир приложения — схема ташкентского метро. Ночью экран — тёмно-синяя эмаль, днём — белая бумага схемы. У каждой задачи свой цвет линии: красная — разговор с ассистентом, синяя — переводчик, зелёная — память, жёлтая — настройки и служебные сообщения. Разговор нарисован линией: ваша реплика — станция, ответ ассистента — пересадка, его шаги (календарь, почта, камера) — короткие остановки, а в конце линии — живая станция, которая дышит вашим голосом и голосом ассистента. Заголовки набраны узким жирным начертанием, как названия станций. Навигация и элементы управления — системные, на iOS 26 с «жидким стеклом». Сделано по методикам [Impeccable](https://impeccable.style) и [unslop](https://github.com/heydamir/unslop) (Damir Sokolovsky, CC BY 4.0).

## Голос

- **ElevenLabs** — нейросетевой голос, звучит как живой человек. Ключ: [elevenlabs.io](https://elevenlabs.io) → Developers → API Keys. Вставьте его в приложении: Настройки → «Голос», выберите голос и нажмите «Проверить голос». Другие голоса добавляются в «My Voices» из Voice Library на сайте ElevenLabs.
  - **v4 Turbo** (по умолчанию): звук идёт потоком и начинается примерно через 0,1 с; говорит по-узбекски, по-русски и по-английски одним голосом. **v4**: выразительнее, медленнее. Прежние модели (Flash v2.5, Multilingual v2, v3) озвучивают ответ по фразам.
  - Три ступени надёжности: поток → по фразам → голос iOS. Если поток не дал звука за 4 секунды, фразы уходят на следующую ступень, ответ не теряется.
- **Голос iOS** — без ключа и как запасной. Скачайте улучшенный: Настройки iPhone → Универсальный доступ → Устный контент → Голоса → Русский → «Милена» или «Юрий». Затем перезапустите приложение.
- **Стерео (A2DP).** Когда вы спрашиваете по кнопке, микрофон на время ответа выключен, и очки получают звук как музыку: стерео, полное качество. В режимах «На связи» и «Без рук» звук остаётся гарнитурным (HFP).

**Снимки экранов без Xcode.** `gh workflow run screenshots.yml` собирает приложение для симулятора и снимает экраны в светлой и тёмной теме (`scripts/ci/screenshots.sh`). Экран с готовыми данными открывает аргумент запуска `-demo <экран>` (`RayBanClaude/App/DemoMode.swift`, только Debug). Скачать: `gh run download <id> -n screenshots`.

Запросы к Claude (`Packages/ClaudeKit/Sources/ClaudeKit/Conversation.swift`):
- модель по умолчанию **Claude Sonnet 5.5** (`claude-sonnet-5-5`), в настройках можно выбрать Haiku 5.5 или Opus 5.5;
- `output_config.effort: "low"` и `thinking: between_tools` (Sonnet 5.5) или `disabled` (Haiku 5.5) — первая фраза без размышления; если сервер не примет настройку, запрос повторяется без неё;
- `context_management` с `clear_tool_uses_20250919` (бета `context-management-2025-06-27`): старые результаты инструментов убираются, когда запрос перерастает ~30 тыс. токенов; заметки памяти не трогаются;
- `fallbacks: "default"` + бета `server-side-fallback-2026-07-01` — если классификатор безопасности отклонит запрос, сервер сам повторит его на fallback-модели;
- автоматическое кэширование промпта (`cache_control` на уровне запроса); дата и время передаются в реплике пользователя, а не в системном промпте, чтобы не ломать кэш;
- история только дописывается — блоки thinking возвращаются без изменений; неудачный ход откатывается целиком.

## Ограничения

- **Публикация.** DAT 1.0 стабилен, но публичный каталог Meta для сторонних приложений ещё не открыт. Для себя — режим разработчика, для тестировщиков — release channels в Wearables Developer Center (там же берутся `MetaAppID` и `ClientToken`). В App Store такие приложения пока не проходят — используйте TestFlight.
- **«Hey Meta» занят Meta AI.** Своё приложение голосом очков не вызвать. Вызвать ассистента с заблокированным телефоном можно через Siri («Джарвис, на связь»), автоматизацию или, в порядке эксперимента, жестом очков.
- **Микрофон в фоне.** Начать слушать из фона iOS разрешает только звонку — отсюда режим «На связи». Обычный режим «Без рук» работает, пока его включили при открытом приложении, и может не пережить телефонный звонок.
- **Сообщения и звонки** требуют разблокированного телефона: iOS показывает окно отправки и подтверждение вызова только на экране.
- **Чужие переписки** (Telegram, WhatsApp, SMS) и уведомления iOS не даёт читать ни одному приложению.
- **API-ключи на устройстве.** Для личного использования ключи хранятся в Keychain. Для раздачи другим людям ключи нужно спрятать за свой сервер-прокси.
- **Батарея очков.** Сессия с очками и видеопоток камеры включаются только по запросу снимка и отключаются через 90 секунд простоя (с включёнными жестами сессия держится постоянно).
- **Не проверено на устройстве.** Пакеты покрыты тестами (память, почта, разбор ответов Claude, потоковые клиенты ElevenLabs на заглушке сокета), приложение собирается в CI, экраны проверены снимками из симулятора. На iPhone с очками не проверены: потоковые протоколы ElevenLabs на живом ключе, звонок CallKit и ответ на него касанием очков, переключение звука, жесты. Для этого и нужен журнал.
